# Pocket CLI releases

Release binaries and installer for `pocket`, which connects your computer to your Pocket agent.

```bash
brew install pocketwalletorg/tap/pocket
```

or

```bash
curl -LsSf https://github.com/pocketwalletorg/pocket-releases/releases/latest/download/pocket-cli-installer.sh | sh
```

Then run `pocket connect` in the folder your agent may use. macOS Apple Silicon only for now.
